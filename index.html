Gemini model checker

Paste your Gemini API key and see which models actually answer for that key, and which of them can use live web search. Use the result to pick the model names for your site.

1. Your key

The key is used only in this open tab and sent only to Google. It is never saved. Close the tab when you are done.

2. Choose what to test

Each model uses up to 2 of that model's own free requests (one plain answer, one with web search). Models that look stable are ticked.

    3. Results

    How to read the results

    Works: the model answered. Not available: Google no longer serves it, or not to this key. Limit reached: it exists but this key has no requests left for it today, or no free quota at all. Rejected: Google refused the request (the reason is shown). Answered, no search: it replied but did not use web search.
